 🖤 Kira Es city

## 🚀 Демо

Открой `index.html` в браузере — и модель уже на экране!

**Управление:**
- 🖱 Клик по экрану — захват мыши
- 🖱 Вращение — перетаскивание
- 🔍 Скролл — приблизить/отдалить
